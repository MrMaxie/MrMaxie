I build developer tools and local infrastructure, but I also make games, explore unusual platforms, and try ideas that do not fit neatly into one specialty.

The common thread is wanting to understand the mechanism and solve a real problem.

## Selected open-source work

- **[Arcantry](https://github.com/MrMaxie/arcantry)** - Helps developers find where project decisions, tasks, release notes, and agent guidance belong before changing a repository.
- **[Cadder](https://github.com/MrMaxie/cadder)** - Helps developers run several local web projects behind stable HTTPS addresses without changing each project's normal start command.
- **[FreeTrayGames](https://github.com/MrMaxie/free-tray-games)** - A Windows tray app that tracks free games on Steam, Epic Games Store, and GOG and notifies users about new offers.
